# Static 유니버스 선택 편향 민감도

검증일: 2026-07-21

## 목적

현재 static 16종목은 오늘의 정보로 선정한 후보군입니다. 신규 ETF는 상장 전에
거래되지 않지만, 현재 알려진 성과를 보고 후보군에 편입했을 가능성은 남습니다.
이 분석은 상장 시점 제한과 테마별 제외로 해당 민감도를 정량화합니다.

## 방법

- 기간: 2016-01-06~2026-07-21
- baseline: 현재 static 16종목
- 전략 설정: 현재 v2 기본값, 멀티 인덱스 게이팅 비활성
- 비교:
  - 2023년 이전 상장 종목
  - 2020년 이전 상장 종목
  - 최근 테마 3종목 제외
  - 커버드콜 3종목 제외
  - 최근 테마 leave-one-out
- 실행: `uv run scripts/analyze_universe_selection_bias.py`
- 산출물: `outputs_universe_bias/` (gitignored)

최근 테마는 `0101N0`(AI전력인프라), `463250`(K방산&우주),
`367760`(네트워크인프라)로 정의했습니다. 네트워크인프라는 2020년 상장이므로
`최근 테마 제외`과 `2023년 이전 상장`은 서로 다른 질문입니다.

## 해석

1. **2023년 이후 상장 ETF의 전체 기간 성과 기여는 크지 않았습니다.**
   이들을 모두 제외한 시 CAGR은 0.21%p 낮아졌습니다. 실제 거래는 K방산&우주에서만
   발생했습니다.
2. **최근 테마 기여의 대부분은 네트워크인프라 1종목에서 나왔습니다.**
   해당 종목은 4건의 거래로 전체 기간 CAGR을 약 1.96%p 높였지만 MDD는 3.52%p
   악화시켰습니다. 수익 개선과 집중 위험이 같이 나타났습니다.
3. **커버드콜 3종목과 AI전력인프라는 과거 성과에 기여하지 않았습니다.**
   전략 거래가 없어 제외 전후 결과가 같았습니다. 다만 현재 freeze에서 제거하면 새 전략
   버전이 되므로, 이 결과만으로 v2 유니버스를 변경하지 않습니다.
4. **Static과 auto의 13.5%p CAGR 격차를 전부 선택 편향으로 해석할 수는 없습니다.**
   이번 민감도에서 관측된 최근 테마 3종목의 전체 기간 증분은 1.94%p입니다.
   auto와 static은 광범위한 후보 수, 교체 빈도, 유동성, 종목 구성이 함께 다릅니다.

2023년 이후 구간만 보면 최근 테마 제외 시 CAGR이 56.54%에서 49.40%로
7.14%p 낮아집니다. 이 구간은 짧고 최근 급등장을 포함하므로 지속 가능한 알파로
해석하지 않고 엔드포인트 민감도로만 사용합니다.

## 한계와 다음 단계

이 결과는 **현재 생존한 16종목 내부의 민감도**입니다. 상장폐지 ETF와 각 과거
시점의 실제 선택 가능 종목을 포함하지 않았으므로 선택 편향의 총크기를 추정하지
못합니다. `listed_before_2023`도 현재 생존 종목을 상장일로만 제한한 proxy입니다.

완전한 point-in-time 검증을 위해서는 다음 데이터가 필요합니다.

- 거래일별 ETF 상장·상장폐지 마스터
- 과거 시점별 자산군·복제방법·기초지수 분류
- 각 시점에 사용 가능했던 유동성·NAV·분배금 데이터
- 유니버스 선정 규칙의 사전 동결

이 데이터를 구축하기 전까지 현재 CAGR은 선택 편향 가능성을 포함한 in-sample
상한으로 유지합니다.
