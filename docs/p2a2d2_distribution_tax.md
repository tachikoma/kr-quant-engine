# P2-A-2d-2: 과세표준 기반 분배금 회계

- 실행: `scripts/p2a2d2_distribution_tax.py`
- fixture: `scripts/test_p2a2d2_distribution_tax.py`
- 산출물: `outputs_p2a2d2/` (gitignored)
- 입력: P2-A-2a 80건(기간 내 74건) + P2-A-2b ledger/provenance, 입력 SHA256 검증
- 범위: **일반 과세계좌의 명시적 연구 세율 시나리오**에 한정. ISA·연금·매매차익 과세는 구현하지 않음.

## 1. 기존 세금 처리와 발견된 결함

| 경로 | 기존 동작 |
|---|---|
| legacy price | `ETF_DISTRIBUTION_TAX_PCT`를 **분배금 총액**에 적용(과세표준 구분 없음) |
| strict ledger | 세금 개념 없이 총액 미수금을 지급일에 그대로 현금화 |
| total return | 세전 재투자 |

결함: 운용사가 공시하는 **주당 과세표준액**이 ledger에 없어, 총액 과세와 과세표준 과세를 구분할 수 없었습니다.
이번 변경은 `CorporateAction`에 과세표준액/정책 ID를 추가하고, 미수금은 **총액을 유지하되 원천징수액을 별도 보관**해 지급일에 세후 실수령액만 현금화합니다. 평가액의 미수금도 세후 기준으로 계산해 지급일에 세금만큼 평가액이 급감하지 않도록 했습니다.

## 2. 공식 근거와 가정

| 근거 | 확인 내용 |
|---|---|
| 소득세법 제17조 제1항 제5호 | 집합투자기구로부터의 이익 = 배당소득 |
| 소득세법 제129조 제1항 제2호 나목 | 배당소득 원천징수 14% + 지방소득세 1.4% = 15.4% |
| 소득세법 시행규칙 제13조 | 좌당 배당소득금액은 과세 대상 손익을 제외해 계산(과세표준액 근거) |
| 삼성자산운용 KODEX ISA 가이드(2026-01-13) | 일반계좌 분배금 = MIN(분배금, 과표증분) × 15.4% |

- 계좌 차이(조사만): ISA는 순이익 200만원 비과세 후 9.9% 분리과세, 연금저축·IRP는 계좌 내 과세이연 후 연금 수령 시 3.3~5.5%.
- **가정**: 15.4%는 일반 과세계좌의 연구용 명시 세율이며 모든 상품·계좌·역사 기간의 확정 세율이 아닙니다.
- **미확인**: 원 단위 절사·반올림 규칙은 공식 근거를 확인하지 못해 적용하지 않고 `Decimal` 정확값을 유지합니다. 금융소득종합과세·매매차익 과세는 범위 밖입니다.
