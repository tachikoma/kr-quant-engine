# P1-B-3: Block Bootstrap Monte Carlo 검증 (연구용)

- 실행: `scripts/p1b3_monte_carlo.py` (원본 80조건 재생성 + MC 2,400행, 총 8.64M 경로)
- fixture: `scripts/test_p1b3_bootstrap.py` (9검사)
- 대상: Baseline(동결) / A(daily_risk_off_exit), 위상 0~19, 기본 5bp/1x·고비용 50bp/3x,
  2016-01-05~2026-09-28, 초기자본 100만원
- 방법: **circular moving block bootstrap**(거래비용 포함 일별 순수익률), seed `20261126`
- 기준 재현: CAGR **24.5411%**, MDD **-51.21%**, Sharpe **1.0391** (1e-9)
- 산출물: `outputs_p1b3/` (`source_returns.csv`, `mc_summary.csv`, `mc_phase_summary.csv`,
  `mc_paired_comparison.csv`, `mc_block_sensitivity.csv`, `mc_recovery_summary.csv`,
  `mc_iid_reference.csv`, `mc_quantile_stability.csv`, `p1b3_summary.json`, `provenance.json`)

## 1. 재사용·신규 범위

| 구분 | 내용 |
|---|---|
| 재사용 | `p1b2.run_policy`·`metrics`(검증된 실행·회계), `p0b`(동결 설정·freeze·preflight·평가곡선), `run_etf_strategy` |
| 신규 | MC 러너 1개, 재표본·경로 지표 함수, bootstrap fixture |
| 무변경 | 엔진·`strategy_freeze.json`·실전·스케줄러·유니버스·비용 정책 (P1-B-2의 `exit_origin_date` 연속성 비교는 main에 이미 반영되어 추가 변경 없음) |
| 참고 | 기존 `validate_proxy_stats.py`는 **iid bootstrap**이라 시계열 의존성을 보존하지 못함 → 계열 상관을 보존하는 block bootstrap을 신규 구현(참고군으로 iid shuffle 병기) |

## 2. 원본 평가곡선 재현

- 80개 조건(위상 20 × 정책 2 × 비용 2)의 일별 평가곡선을 동일 조건으로 다시 생성했습니다
  (P1-B-2는 곡선을 저장하지 않아 provenance 재사용이 불가).
- 조건별 일별 수익률은 `source_returns.csv`(199,280행)에 저장했습니다.
- 검증: (a) 수익률 복리 = 평가액(1e-6), (b) 날짜 정렬·중복 없음, (c) NaN/Inf 없음,
  (d) phase 0 기준 재현 1e-9, (e) 80조건 전부 회계 검산.
- phase 0 base 일평균 순수익률 0.108%(거래비용 반영 후).

## 3. Monte Carlo 경로 수·실행

| 항목 | 값 |
|---|---|
| 방법 | circular moving block bootstrap (끝→시작 wrap) |
| 블록 길이 | 5 / 10 / 20 / 60 (기준 20) |
| 투자 기간 | 252 / 756 / 1260 거래일 |
| 경로 수 | 조건별 2,000 → 기준 블록 20에서 10,000 확장 |
| 총 경로 | 8,640,000 |
| seed | 20261126 (조건별 파생, 사전 고정) |
| paired | Baseline/A가 **동일 블록 인덱스** 사용 |

- 2,000 → 10,000 확장 시 분위수 차이: 중앙 1.13%p, 최대 **5.58%p**(CAGR p95 꼬리).
  꼬리 분위수는 10,000에서도 불안정하므로 분포 요약은 중앙·p05 중심으로 읽습니다.
- 비율 지표 표본오차는 `sqrt(p(1-p)/N)`으로 전 지표(원금 미달·미회복·종료 시 고점 미달·TUW>1년·
  MDD/손실 임계치)에 기록했습니다(예: 5년 원금 미달 1.86% → SE 0.14%p, 10,000경로).
- 비용은 이미 수익률에 포함되어 재표본에서 다시 차감하지 않습니다(fixture 검증).

| 비용 | 기간 | CAGR p05 | p50 | p95 | 원금 미달 | MDD 중앙 | MDD p05 | -50% 이하 비율 |
|---|---|---|---|---|---|---|---|---|
| base | 1년 | -14.90% | 24.65% | 96.71% | 14.95% | -14.35% | -39.20% | 0.87% |
| base | 3년 | -0.17% | 26.69% | 62.68% | 5.13% | -22.69% | -48.01% | 3.77% |
| base | 5년 | 4.95% | 26.32% | 53.85% | **1.86%** | -31.91% | -52.75% | 7.42% |
| stress | 1년 | -19.72% | 17.99% | 86.78% | 22.65% | -15.97% | -40.26% | 1.01% |
| stress | 3년 | -5.98% | 20.17% | 55.78% | 11.00% | -25.69% | -51.28% | 5.87% |
| stress | 5년 | -0.55% | 19.83% | 45.78% | 5.52% | -33.11% | -55.62% | 10.10% |

- 1년은 손실 확률이 15%(base)/23%(stress)이고 CAGR p05가 -14.9%/-19.7%입니다.
  기간이 길수록 원금 미달 확률은 줄지만(5년 1.9%/5.5%) **MDD 꼬리는 오히려 두꺼워집니다**
  (5년 p05 -52.8%/-55.6%).
- 중간 손실(초기자본 대비 -30%/-50%) 비율(5년 base): 9.75%/1.13%.
- 5년 누적수익률 p05/p50: Baseline +27.3%/+221.6%, A +29.5%/+205.8%(최종 평가액 중앙 3.22M/3.06M).
- 5년 MDD가 -20/-30/-40/-50% 이하인 경로: 77.4/53.5/24.9/7.4%.

## 5. 극단 MDD·미회복 위험(5년, phase 0)

| 지표 | Baseline | A |
|---|---|---|
| MDD 중앙 | -31.91% | -25.00% |
| MDD p05 / p01 | -52.75% / -63.31% | -45.23% / -55.00% |
| MDD ≤ -50% 비율 | 7.42% | 2.51% |
| 최대 TUW 중앙 / p95 | 298 / **776일** | 303 / 763일 |
| TUW > 1년 비율 | 62.1%(SE 0.49%p) | 63.5% |
| **최대 낙폭 구간 미회복** 비율 | **22.1%**(SE 0.41%p) | 21.8% |
| **종료 시 고점 미달** 비율 | **89.1%**(SE 0.31%p) | 89.4% |
| 낙폭 회복일 중앙 / p95(회복 경로) | 128 / 505일 | 117 / 465일 |

- 두 "미회복" 지표를 구분합니다.
  (a) **최대 낙폭 구간 미회복 22.1%**: 최대 낙폭 직전 고점을 종료까지 회복하지 못한 경로(회복 미완료는
  회복으로 간주하지 않음, 초기 자본을 고점 기준에 포함).
  (b) **종료 시 고점 미달 89.1%**: 이후 신고점을 만든 뒤 다시 하락한 경로까지 포함해, 종료 시점 평가액이
  그 시점까지의 최고점보다 낮은 경로. (a)와 (b)는 다른 지표이며 (b)가 훨씬 큽니다.
- A는 MDD 꼬리를 줄이지만(≤-50% 7.4→2.5%) **미회복·TUW 지표는 거의 개선되지 않습니다.**
  방어는 낙폭 깊이에서 발생하고, 회복 속도에서는 발생하지 않습니다.

## 6. 위상별 위험 분포(5년, 10,000경로, base)

| 항목 | Baseline | A |
|---|---|---|
| CAGR p50: 중앙 / 범위 | 19.64% / **8.9~27.3%(18.4%p)** | 20.43% / **12.8~25.3%(12.5%p)** |
| CAGR p05: 중앙 / 범위 | -0.93% / -10.6~6.1% | 1.44% / -3.5~5.3% |
| MDD p05: 중앙 / 범위 | -52.5% / 26.1%p | -47.3% / 13.3%p |
| 원금 미달: 중앙 / 범위 | 5.91% / 1.4~22.4% | 3.64% / 1.6~10.2% |
| 미회복: 중앙 / 범위 | 30.3% / 21.5~50.2% | 27.5% / 21.5~37.0% |
| phase 0 위치(CAGR p50) | **2/20** (p90) | 2/20 (p90) |
| phase 0 위치(MDD p05) | **13/20** (p35) | 5/20 (p75) |
| phase 0 위치(원금 미달) | 3/20 | 2/20 |

- 위상 선택만으로 5년 CAGR p50이 **18.4%p** 움직입니다(8.9~27.3%). phase 0은 수익·원금 손실
  측면에서 상위(2~3위)지만 **MDD 꼬리는 중앙보다 나쁩니다(13/20)**.
- A는 위상 간 분산을 줄입니다(CAGR 범위 18.4→12.5%p, MDD 범위 26.1→13.3%p).
- 20개 위상은 독립 표본이 아니며, 위상을 균등 혼합한 분포는 **가정된 혼합 분포**일 뿐 실제
  단일 전략의 수익률 분포가 아닙니다(혼합 수치는 본문 표에 사용하지 않음).

## 7. 후보 A paired comparison(동일 경로)

5년(1260일), 블록 20, phase 0~19 × 비용 2:

| 지표 | base 중앙 | stress 중앙 |
|---|---|---|
| ΔCAGR (A−Baseline) | +0.03%p | -0.06%p |
| ΔMDD | **+0.25%p** | **+0.17%p** |
| Δ최종 평가액(중앙) | +2,152원(+0.2%) | -4,745원(-0.5%) |
| 원금 미달 비율 변화 | -0.30%p | -0.04%p |
| ΔTUW(중앙) | 0일 | 0일 |
| ΔMDD ≥ 5%p 개선 경로 비율 | 29.9% | 26.2% |
| ΔCAGR ≤ -1%p 악화 경로 비율 | 20.6% | 23.5% |
| 두 조건 동시 발생 | 0.2% | 0.2% |

- 경로별 중앙 ΔMDD는 사실상 0이지만 **꼬리에서는 개선**됩니다(5년 MDD p05 -52.8→-45.2%p,
  ≤-50% 비율 7.4→2.5%). 즉 A는 "평균적 개선"이 아니라 **최악 경로 완화**입니다.
- ΔMDD ≥5%p 개선은 경로의 약 30%에서만 발생하고, 동시에 CAGR -1%p 이상 악화는 20~24%에서
  발생합니다(동시 발생은 0.2%로 드묾 — 서로 다른 경로에서 나타남).
- 1년에서는 원금 미달 비율이 오히려 소폭 악화(base 14.95→15.28%, stress 22.65→23.94%)됩니다.

## 8. 2026 제외·비용·블록 길이 민감도

**2026 제외(5년, phase 0, base)**: Baseline p50 18.18%/-28.4%(MDD p05), A 17.72%/-28.3%
→ **A의 MDD 꼬리 개선이 -0.1~-0.2%p로 사라집니다.** 2026년 블록을 제외하면 방어 효과 대부분이
사라진다는 P1-B-2 결론과 일치합니다.

**블록 길이(phase 0, 5년, base)**:

| 블록 | Baseline p50 / MDD p05 | A p50 / MDD p05 |
|---|---|---|
| 5 | 26.93% / -46.29% | 25.86% / -39.88% |
| 10 | 26.51% / -47.71% | 25.65% / -41.74% |
| **20** | **27.01% / -52.58%** | **25.84% / -45.62%** |
| 60 | 25.71% / -54.72% | 24.80% / -43.73% |

- 블록이 길수록 MDD 꼬리가 두꺼워집니다(직렬 상관 보존). A의 방향성(수익 -1%p 내외, MDD p05
  +6~7%p)은 모든 블록에서 유지됩니다. ex2026에서는 블록 20 기준 A의 MDD 개선이 +0.3%p로 축소됩니다.
- **iid shuffle 참고군**(5년 base): p05 5.74%, MDD p05 -47.73%, 미회복 22.7%로 block(5.0%,
  -52.8%, 22.1%)보다 꼬리가 얇습니다. 일별 독립 셔플은 시계열 의존성을 제거하므로 참고용입니다.

## 9. 기존 전략과 A의 연구상 판단

- **Baseline**: 5년 기준 CAGR p50 26.3%, p05 5.0%지만 MDD p05 -52.8%, 최대 낙폭 구간 미회복 22.1%,
  종료 시 고점 미달 89.1%.
  위상 선택에 따라 p50이 8.9~27.3%로 크게 달라져, 단일 역사 경로(24.54%)를 점추정으로 쓰면 안 됩니다.
- **A**: 위상 분산과 MDD 꼬리를 줄이지만(≤-50% 7.4→2.5%), 경로 중앙값 개선은 ~0이고
  2026 제외 시 방어 효과가 사라집니다. 1년 원금 미달은 오히려 악화됩니다.
- **판단 유지: A는 보류(hold).** Monte Carlo는 “최악 경로 완화”를 확인했지만, 그 효과가
  2026 단일 급락에 집중되고 완료 fold/2026 제외에서 재현되지 않으므로 채택 근거가 되지 않습니다.

## 11. 한계

- **관측 수익률의 재표본**이며 새로운 가격 경로에서 매매 결정을 다시 실행한 시뮬레이션이 아닙니다.
  역사에 없던 급락·유동성 고갈·구조 변화를 검증하지 않습니다.
- 손실 비율은 모형 가정에 따른 추정치이며 미래 손실 확률을 보장하지 않습니다. 독립 OOS가 아닙니다.
- 위상 20개는 독립 표본이 아니고, 위상 혼합 분포는 실제 단일 전략 성과가 아닙니다.
- 꼬리 분위수는 2,000→10,000에서 최대 5.6%p 변동해 불안정합니다(중앙·p05 중심 해석).
- 블록 부트스트랩은 20거래일 내 상관만 보존하며, 레짐 전환·장기 의존성은 별도 검증이 필요합니다.
- 2026년은 부분연도(180일)이며 freeze 이후 46거래일은 모니터링입니다.
- PIT·기업행위·분배금 승인 blocker는 유지됩니다.
