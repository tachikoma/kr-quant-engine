## 5. 리밸런싱 위상 민감도 — **미검증**

- legacy에서 위상을 바꾸는 유일한 경로는 `initial_state`의 `rebalance_phase_offset`이며, 이는
  상태 재개 경로로 **`daily_risk_off_exit` 가드에서 차단**됩니다(A 사용 불가).
- `initial_state`는 `warmup_days=0`으로 시작하므로 baseline/B2/B3도 canonical과 동일 경로가
  보장되지 않습니다. offset 0·260거래일 probe에서는 첫 체결일(2016-08-01)과 최종 평가액이
  일치했지만, 4개 후보를 동일 위상에서 비교할 수 없습니다.
- 따라서 offset 0/5/10/15 비교는 **미검증**으로 남깁니다(`phase_status.json`).
  후속 과제: pending 청산 상태 직렬화 + 워밍업을 보존하는 명시적 phase 파라미터.

## 9. 한계

- 중첩 롤링 구간은 **독립 표본이 아니며** WFA/OOS 검증이 아닙니다.
- 2026년 제외 실행은 종료일만 2025-12-31로 바꾼 별도 실행이며, 마지막 날 이후 이벤트는 없습니다.

- 체결 가정은 P0-B와 동일(모의), PIT·기업행위·분배금 blocker 유지.
- `회전`은 `calc_trading_stats`의 gross turnover(매수+매도 체결대금/평균 평가액)로 통일했습니다.

  정정했습니다(baseline 56.26, A 62.07, B2 78.84).
