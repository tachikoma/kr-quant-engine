### 신규 파라미터(`rebalance_phase_offset`)

- 정기 리밸런싱 일정만 `(i - warmup + offset) % REBALANCE_STEP_DAYS == 0`으로 이동합니다.
- **기본값 0은 기존 동작과 완전히 동일**: 결정일 125건·지표가 기준 재현과 1e-9 이내로 일치합니다.
- `0 ≤ offset < REBALANCE_STEP_DAYS`만 허용하고, `approval_strict`·`ohlcv_capacity`·`initial_state`
  조합은 `ValueError`로 차단합니다(미검증 조합).
- 위험 관리 검사 주기(`exit_check_days`)는 위상과 독립입니다(별도 offset 유지, fixture 검증).
- 실전 경로에서는 전달하지 않습니다(`live_trading/` 무변경).

## 2. 비교 기준(워밍업·공통 구간)

- 각 변형은 **자연 워밍업** `max(120, MARKET_MA_DAYS + MARKET_SLOPE_DAYS)`으로 실행합니다
  (120/135/140/145/160거래일).
- 워밍업을 165일로 강제하면 `165 - 140 = 25 ≡ 5 (mod 20)`이라 **리밸런싱 원점이 5일 이동**해
  위상 실험이 오염됩니다. 그래서 공통 워밍업 대신 **공통 평가 구간**을 사용했습니다.
- 모든 실행은 (a) 전체 기간(P0-D 관례: 워밍업 구간은 현금으로 CAGR 희석)
  (b) **공통 구간 2016-09-05~2026-09-28**(`win_*`, 2,466거래일) 두 세트를 기록하고,
  안정성 판정은 (b)를 기준으로 합니다. `window_start`·`warmup_days`·
  `effective_phase_vs_140`을 행마다 남겼습니다.
- MA 변형은 워밍업과 **risk_on 적격 집합**이 동시에 변합니다. 즉 "게이트만 바꾼 실험"이 아니라
  MA 기간 파라미터 전체의 민감도입니다.
- MA·slope 지표는 캐시 컬럼을 재사용하지 않고 **동일 원본 종가에서 재계산**했으며, 재계산 결과가
  캐시 지표와 동일함을 실행 전에 검증했습니다(`risk_on` 포함).

## 5. 실험 C — 사전 고정 18개 교차 조합 및 안정 영역

- base CAGR 17.25~27.47%(spread 10.22%p), stress 11.74~21.31%(spread 9.58%p),
  **비용 조건 간 Spearman 0.986**(n=18·동일 경로 중첩, 탐색적).
- plateau(공통 구간 **CAGR·Sharpe·MDD 논리곱**) **6/18(33%)**, CAGR 단독 통과도 6/18,
  기준 조합은 **5위/18**(base·stress 동일).
- 상위: `w0/r20/p2` 27.47%, `w0.25/r20/p2` 27.00%, `w0/r20/p3` 25.27%, `w0.25/r20/p3` 25.16%,
  `w0.55/r20/p2` 24.54%. 리밸런싱 20일이 모든 가중치에서 지배적입니다(15/25는 -5~7%p).
- 사전 등록 후보 게이트(plateau 기준 포함, 최대 2개):
  1단계(MDD 5%p·CAGR -2%p·Sharpe -0.10·고비용 상위 절반·2026 제외 기준 이상) 통과 **2개**
  (`w0/r20/p2`, `w0.25/r20/p2`).
  2단계에서 두 조합 모두 **위상 범위**(18.25%p/17.55%p > 기준 자신의 범위 16.39%p)와
  **인접 조합 중앙값**(26.18% < 27.35%p/26.83%p 요구)에서 탈락했습니다.
- 따라서 **교차 격자 후보는 0개**입니다(사전 등록 null 규칙: 게이트 사후 완화 금지).
- 해석: 최고 CAGR 조합은 기준보다 수익은 높지만 **위상 분산이 더 크고** 인접 조합(가중치·종목수
  이웃)이 뒷받침하지 않습니다. 즉 "안정 영역"이 아니라 "한 점의 우연"에 가깝습니다.
- 격자가 동결값에 대해 단측·코너(가중치 상한 0.55, 종목수 하한 2)이므로 인접 중앙값 게이트가
  구조적으로 불리하다는 점은 그대로 보고합니다(`n_neighbors`·`at_grid_corner` 기록).
