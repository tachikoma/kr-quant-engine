# P2-A-2a 부속: 2026-03-05 / 07-31 / 08-03 가격 이상 원인 조사

- 실행: `scripts/p2a2a_price_anomaly.py` (읽기 전용)
- 산출물: `outputs_p2a2a/price_anomaly/` (`price_anomaly.json`, `price_anomaly_tickers.csv`,
  `price_anomaly_breadth.csv`, `price_anomaly_impact.csv`)
- 원칙: **운영 캐시를 수정하지 않는다.** 원인을 확정하지 못하면 `원인 미확인`으로 남긴다.
  동일 원천 재조회만으로 독립 검증을 주장하지 않는다.

## 1. 대상과 방법

| 구분 | 내용 |
|---|---|
| 날짜 | 2026-03-05, 2026-07-31, 2026-08-03 (전후 각 8일) |
| 종목 | 동결 16종, KOSPI·KOSPI200 |
| 캐시 | `data_cache/*.parquet` OHLCV·NAV |
| KRX 재조회 | pykrx `get_etf_ohlcv_by_date` (동일 원천, 정규화 경로 검증용) |
| 독립 원천 | **KIS 조회 전용** `inquire-daily-itemchartprice` (주문·잔고 API 미사용) |
| 횡단면 | KRX 전종목 ETF 스냅샷(1,072~1,155종)의 등락률 분포 |
| 분할·병합 | 같은 스냅샷의 `LIST_SHRS` 전일 대비 |
| 기업행위 | ledger 0건, KIND 403 → **미확보** |

KIS는 `FID_ORG_ADJ_PRC`를 0과 1로 각각 조회했다. **라벨과 실제 동작이 반대로 관측**되어
(0이 배당락 하락을 제거한 조정 계열, 1이 원주가) 라벨이 아니라 캐시 일치와 배당락일
수익률 차이로 판정했다.

## 2. 결과

| 날짜 | KOSPI | KOSPI200 | ETF 중位数 | \|10%\| 초과 비중 | 캐시=KIS(원주가) | 상장좌수 변화 | 판정 |
|---|---:|---:|---:|---:|---|---|---|
| 2026-03-05 | **+9.63%** | **+9.84%** | +2.01% | 21.7% | 16/16 (차이 0.0%p) | 분할급변 없음(최대 1.16배) | 시장 변동 |
| 2026-07-31 | **+17.91%** | **+19.98%** | +2.70% | 29.9% | 16/16 (차이 0.0%p) | 분할급변 없음(최대 1.04배) | 시장 변동 |
| 2026-08-03 | **−5.12%** | **−5.74%** | −0.18% | 2.4% | 16/16 (차이 0.0%p) | 분할급변 없음(최대 1.01배) | 시장 변동 |

- KRX 재조회 OHLCV는 캐시와 **전 필드 동일**(최대 차이 0). 정규화·수집 과정 오류는 없다.
- KIS 원주가 수익률은 캐시와 **16종 전부 일치**(최대 차이 0.0%p, 반올림 제외). 독립 증권사
  피드도 같은 변동을 보인다.
- `LIST_SHRS`는 ETF 설정/환매로 매일 변한다(당일 최대 1.16배). **±50% 이상 급변은 없어**
  분할·병합 영향으로 보지 않는다.
- NAV도 같이 움직였다(예: 069500 07-30 87,653 → 07-31 105,157). NAV는 구성종목 가격에서
  산출되므로, ETF 종가만의 오류로 설명되지 않는다.
- 07-31 괴리율(종가/NAV−1)은 069500 +3.48%, 102110 +3.95%로 급등 당일 프리미엄이
  확대됐다. 이는 가격 이상이라기보다 급등장의 호가 괴리로 해석된다.

### 분류

| 가능성 | 판정 | 근거 |
|---|---|---|
| 실제 시장 급등락 | **채택(데이터 내)** | 지수·NAV·KIS 원주가·캐시가 같은 방향·크기 |
| 특정 캐시 손상 | 기각 | 캐시=KRX=KIS, 16종 전부 |
| KRX 원천 오류 | **남음(검증 불가)** | KIS도 같은 값을 주므로 원천 간 일치는 확인, 실세계 대조는 범위 밖 |
| 날짜/종목 매핑 오류 | 기각 | 16종·지수·스냅샷이 동일 날짜에 정합 |
| 수정주가·분할·병합 | 기각 | 분할급변(±50%) 없음, 원주가/조정 계열 모두 같은 방향 |
| 수집·정규화 오류 | 기각 | KRX 재조회와 전 필드 차이 0 |

**결론: `anomaly_confirmed`(독립 피드 일치)이며 캐시·수집 오류는 아니다.** 다만 이 환경
밖의 실세계 데이터와 대조하지 않았으므로 "실제 시장"이라는 최종 확정은 하지 않는다.

## 3. 기존 연구 영향

| 날짜 | 보유 | 평가액 변화 | 분배금 현금 | 리밸런싱/체결 | 시장 필터 |
|---|---|---:|---:|---|---|
| 2026-03-05 | 091160, 367760 | **+15.28%** | 0 | 없음 | risk_on=True |
| 2026-07-31 | 091160, 367760 | **+29.29%** | 0 | 없음 | risk_on=False |
| 2026-08-03 | 091160, 367760 | **−6.67%** | 0 | 없음 | risk_on=False |

- 해당 날짜에 **체결·리밸런싱 결정이 없다.** 평가액은 보유 종목의 가격 재평가로만 움직였다.
- 2026-03-05는 시장 필터가 risk_on이었으나 리밸런싱 주기가 아니어서 주문이 없었다.
- 07-31·08-03은 risk_off 상태로 신규 진입이 없었고, 급등락이 필터 상태를 바꾸지 않았다.
- 영향 범위: 2026년 in-sample 성과·MDD·변동성 지표 전부. P0~P1 연구도 같은 캐시를 쓰므로
  같은 날짜의 수익률·리스크 지표에 동일하게 반영되어 있다. **재실행하지 않았다.**
- 가격 캐시는 원주가로 확인되어(별도 문서 §5) 분배금 가산과 이중 계상되지 않는다.

## 4. 조치

- 운영 캐시는 수정하지 않는다. 원인 오류가 확인되지 않았기 때문이다.
- 만약 이후 실세계 대조에서 원천 오류가 확인되면: (1) 해당 일자만 격리하는 연구용
  outlier 마스크를 별도 산출물로 만들고, (2) 원본 캐시는 보존한 채 재수집·재검증하고,
  (3) 영향받는 2026년 지표를 재산출한다. 이번 범위에서는 하지 않는다.
- 연구 파이프라인에는 `anomaly_detected`(캐시 |수익률|>15%)와 `anomaly_confirmed`
  (독립 피드 일치)를 분리해 기록한다.
